This project analyzed Jeonse price data collected through web scraping. I used multiple regression, hedonic price modeling, and machine learning to study how loan eligibility relates to Jeonse prices in Seoul's Gwanak District.

The analysis found a 25% difference in Jeonse prices associated with loan eligibility.
